# Test-first benchmark workflow

1. Read the task and nearby code.
2. Run the smallest useful existing check.
3. Add or improve a test that describes the requested behaviour.
4. Make the smallest code change that passes the test.
5. Run the focused check again, followed by the wider supplied checks.
